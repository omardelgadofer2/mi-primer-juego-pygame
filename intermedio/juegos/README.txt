🎮 Mi Primer Juego en Python
¡Hola! Este es mi primer videojuego, un proyecto desarrollado con el objetivo principal de aprender las bases del desarrollo de juegos, la lógica de programación y el flujo de trabajo en este mundo.
🛠️ Requisitos y Dependencias
Para poder ejecutar el juego y cargar correctamente todos los assets (incluyendo los mapas), necesitas tener instalado Python y las siguientes librerías:
• Pygame: El motor principal del juego.
• pytmx (o la librería que uses para Tiled): Necesaria para interpretar y renderizar el mapa diseñado en Tiled.
Puedes instalarlas ejecutando en tu terminal:
bash
pip install pygame pytmx
Usa el código con precaución.
⚠️ Estado actual del proyecto (Bugs conocidos)
El juego está "terminado" o... bueno, ahí más o menos. Como es mi primer proyecto, hay un par de detalles que se quedaron a medias:
• Enemigos bugeados: Su comportamiento o rutas pueden hacer cosas raras.
• Colisiones inestables: En algunos puntos las colisiones fallan o te pueden atravesar.
Nota honesta: Trabajar con colisiones y físicas en Pygame desde cero es un verdadero dolor de huevos. Decidí dejarlo así por ahora porque el propósito principal era aprender cómo funciona todo el ciclo de un juego, y esa meta ya está cumplida. ¡Espero que disfrutes probando el resultado de mi aprendizaje!
